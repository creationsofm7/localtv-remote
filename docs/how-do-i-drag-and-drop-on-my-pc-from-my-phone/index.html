How do I drag and drop on my PC from my phone?

In the LocalTV Remote controller, move the Windows cursor onto an item, tap Hold, swipe across the trackpad to move it, then tap Release over its destination. This holds and releases the PC's left mouse button; it does not move a file from your phone to your PC.

You need an active connection to your Windows PC first. The large trackpad on the Remote tab moves the existing desktop cursor. If you have only used taps and swipes so far, see the phone-as-mouse guide for the basic gestures before trying a drag.

Drag a Windows item

  1. Find the item on the PC screen. Open the folder or app containing it and identify where you want to drop it. The phone controller sends input, but you still look at the PC display to see the item and target.
  2. Position the cursor. On your phone, stay on the Remote tab and swipe on the area labeled Swipe to move cursor. Stop when the Windows cursor is over the item. Do not tap the trackpad yet.
  3. Hold the left button. Tap Hold below the trackpad. The control becomes active and changes to Release. On the PC, this is the start of a normal left-button drag.
  4. Move to the destination. Swipe on the trackpad while the left button remains held. Use several short swipes if the destination is far away. Watch the PC screen so you can stop over the correct folder, window, or other drop target.
  5. Release deliberately. Tap Release. That sends the mouse-up action to Windows and ends the drag. Check the result on the PC before starting another one; some apps reject drops or use their own rules for what a drop does.

When a drag does not land where you expected

If the item was selected but did not move, check whether Hold became Release before you swiped. A quick tap on the trackpad can act like a click instead of a drag. Start again with the cursor directly on the item, then make a deliberate first movement. If the cursor travels too far, reduce Pointer speed in the controller settings and try shorter swipes.

Releasing over an empty area may not have the same effect as releasing over a valid target. For example, a window edge may resize instead of moving, and a file manager may copy or move an item according to Windows rules. Confirm the outcome on the PC rather than assuming every drag has the same result.

Limits: This is mouse input on the PC, not file transfer, screen mirroring, or control over the internet. The phone and PC must be reachable on the same local network. A disconnected controller cannot finish an in-progress drag; reconnect and check the Windows desktop before continuing.
