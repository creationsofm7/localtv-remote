A free, open-source Unified Remote alternative for Windows

If you came here looking for a free Unified Remote alternative, here's the honest version. LocalTV Remote does one thing: it turns your phone into a mouse, keyboard and volume remote for a Windows PC, and it does that with no app on your phone, no account, and no cloud. Below is a side-by-side comparison, including the cases where Unified Remote is the better choice.

When LocalTV Remote is the better pick

You're on Windows, you want a free and open-source tool, and you don't want to install anything on the phones doing the controlling. Pair each phone separately to use the same Windows cursor, keyboard, volume and media-key controls. Input stays on your local network, with no cloud relay or account.

When Unified Remote is the better pick

You need macOS, Linux or Raspberry Pi support, Bluetooth on Windows, Wake On LAN, or app-specific remotes. Unified Remote also offers custom remotes and a Screen Viewer in Full. LocalTV Remote sends ordinary playback and browser keys to the focused application and can request Sleep or Shutdown after confirmation; it does not provide those application integrations, screen streaming or remote wake.

LocalTV Remote controls Windows input over a trusted local network and does not provide internet remote access. Read how Sleep and Shutdown work.
