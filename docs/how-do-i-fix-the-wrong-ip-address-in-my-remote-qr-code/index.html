How do I fix the wrong IP address in my remote QR code?

Open Network settings in the LocalTV Remote pairing window on your PC. If Automatic picked an address your phone cannot reach, select the PC's Wi-Fi or Ethernet interface that belongs to your phone's local network. The pairing window will refresh its address and QR code; scan the new code.

A PC can have several network addresses at once. VPNs, virtual adapters, and multiple Wi-Fi or Ethernet connections may make the automatically selected address unsuitable for the phone. This guide is about choosing the address printed in the QR code. For a broader check of guest Wi-Fi, router isolation, and other connection problems, use the phone-to-PC Wi-Fi guide.

Select the address your phone can reach

  1. Keep the pairing window open on the PC. Look at the full controller address displayed below its QR code. The numeric part before the port is the PC address currently being advertised to your phone.
  2. Open Network settings. Select the settings icon in the top-right area of the PC pairing window. Under Connection network, you will see Automatic (recommended) and the available PC network interfaces with their addresses.
  3. Pick the reachable interface. Choose the PC's active Wi-Fi or Ethernet connection to the router your phone uses. Avoid a VPN or virtual adapter address if your phone cannot reach that network. The interface name and address are shown together so you can compare them with the connection you expect.
  4. Use the refreshed QR code. Selecting an interface updates the server's advertised address and reloads the pairing window. Scan the QR code now displayed, not a screenshot or bookmark from before the change. You can also type the newly displayed controller address into the phone browser.
  5. Test from the phone. Keep the phone on Wi-Fi and open the new address. If the pairing page loads, enter the code currently shown on the PC and try a harmless pointer movement. If the page still does not load, try another listed interface that the phone can reach.

If the new address still will not open

Choosing an interface changes which PC address appears in the pairing link; it does not join your phone to that network or change the router. If your phone is on mobile data, guest Wi-Fi, or an isolated wireless network, it may be blocked from contacting the PC even when the address is correct. Put both devices on a local network that permits device-to-device traffic. A PC on Ethernet and a phone on Wi-Fi can work when both are reachable through the same router.

Windows Firewall can also block the connection. Keep the firewall enabled and review the program rule using the Windows Firewall guide. If the QR image itself is difficult to scan but the printed address looks right, use the manual address and code instructions instead.

Limits: LocalTV Remote uses the local network, not an internet relay. A manual interface selection cannot overcome router isolation or make an offline PC reachable. If that interface disappears, the app may return to Automatic; check the address shown in the current pairing window before reconnecting.
