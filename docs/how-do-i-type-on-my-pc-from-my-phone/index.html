How do I type on my PC from my phone?

Pair your phone with LocalTV Remote, click the text field you want to edit on the Windows PC, then type into the controller’s “Type here…” box. New text and supported editing keys are sent to the active Windows application.

LocalTV Remote is installed on the Windows PC; the phone uses a browser page. Complete the general setup guide if the controller is not connected yet. Once connected, the important detail is focus: the PC application must have its cursor in the field that should receive the text.

Send text to Windows

  1. Focus the destination on the PC. Use the phone trackpad or the PC mouse to click a search box, document, message field, or another editable control. A blinking caret is a useful sign that the field is ready.
  2. Use the quick text box. On the Remote tab, tap “Type here…” to open your phone keyboard. Start with a short test in an empty Notepad document. Add text at the end of the phone box and watch where it lands on the PC.
  3. Send editing keys. Enter, Backspace, Delete, Escape, Tab, and the four arrow keys are handled as individual key presses. Your phone keyboard can send some of them directly; the Input tab also provides dedicated buttons.
  4. Use the Input tab for navigation. Tap Input for Enter, Space, Tab, Esc, Home, and a directional pad. The center OK button sends Enter. The button labeled Delete sends Backspace, removing the character before the PC caret, not the one after it.
  5. Clear carefully. The clear button beside “Type here…” removes the current controller text and sends the corresponding Backspace presses to the PC. It is not merely a visual reset.

Limits and practical checks

This is remote keyboard input, not screen mirroring. The phone does not show the contents or selection state of the Windows field, and the controller text box is not a synchronized copy of the PC document. Phone keyboards, browsers, input methods, and Windows applications can handle composition, autocorrect, shortcuts, or protected fields differently.

Avoid editing the middle of the phone text box. Moving its caret does not move the PC caret. Replacements and deletions can therefore affect the wrong text. Some keyboard/browser combinations can also send more than one deletion event. Test deletion in a disposable document before editing anything important, and correct existing text directly on the PC when in doubt.

If text appears in the wrong place, refocus the intended Windows field before typing. If characters do not arrive, try a dedicated key in an empty document. Elevated or protected Windows surfaces may not accept injected input.
