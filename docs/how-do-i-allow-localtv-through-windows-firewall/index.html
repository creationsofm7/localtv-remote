How do I allow LocalTV Remote through Windows Firewall?

Allow the LocalTVRemote.exe program on trusted Private networks. Do not turn off Windows Firewall and do not enable broad access on Public networks.

First, check the existing rule

  1. Open Windows Security, choose Firewall & network protection, then Allow an app through firewall.
  2. Select Change settings if Windows permits it. Find LocalTV Remote or the installed LocalTVRemote.exe.
  3. Enable the app for Private networks. Leave Public unchecked. The installer itself requests a program-scoped inbound rule named “LocalTV Remote” for Private and Domain profiles; program scope matters because the daemon may move from its preferred port when that port is busy.
  4. Apply the change, reopen LocalTV Remote, and use the current address displayed in its pairing window from the phone.

If LocalTV Remote is not listed

Choose Allow another app, browse to the installed LocalTVRemote.exe, add it, and allow only the appropriate trusted profile. The default installer location is normally under Program Files\LocalTV Remote, but use the executable’s actual installed location rather than guessing.

Reinstalling the latest release can also recreate the installer-managed rule. If Windows asks for administrator approval, review the executable path and publisher details before approving. LocalTV Remote’s installer can run per-user, but changing firewall policy may still require elevated permission.

SituationSafe action
Trusted home Wi-Fi marked PrivateAllow the LocalTV Remote program on Private.
Cafe, hotel, airport, or other Public networkDo not broaden the rule. Use a trusted private LAN instead.
Work or school PCAsk IT to approve the program-scoped rule and network path.
Third-party security suite controls trafficAdd an equivalent program rule there, following its vendor guidance.
Phone still cannot open the addressCheck same-network access and guest/client isolation next.
Security limitation: the phone controller uses plain HTTP and WebSocket traffic on the local network, not encrypted HTTPS. A firewall rule only controls reachability; it does not encrypt that traffic. Use LocalTV Remote on a network you trust.
