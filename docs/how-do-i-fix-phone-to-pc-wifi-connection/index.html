How do I fix my phone-to-PC Wi-Fi connection?

If the PC changed networks or received a new local IP address, quit LocalTV Remote from its tray menu and launch it again. Then use the newly displayed address and confirm that the phone and PC can talk directly on the same local network.

Check the connection in this order

  1. Confirm LocalTV Remote is running. Open it from the Start menu or tray. Keep the pairing window open while checking the address. If the app is not running, the phone has no local server to reach.
  2. Use the address shown now. Type the complete http://... address from the pairing window into the phone browser. LocalTV Remote prefers port 6776, but the daemon checks successive ports when that one is occupied. It may use any available port from 6776 through 6795, so an old bookmark can point to the wrong place.
  3. Put both devices on the same LAN. Connect the phone to Wi-Fi, not mobile data, and make sure the PC is on that same router by Wi-Fi or Ethernet. A wired PC and Wi-Fi phone can work together when the router places them on the same local network.
  4. Leave guest or isolated Wi-Fi. Guest networks, client isolation, AP isolation, and some workplace networks block one device from opening another device's local address. Move both devices to a normal trusted network, or ask the network administrator whether device-to-device traffic is allowed.
  5. Check the Windows network profile and firewall rule. Use a Private profile on a trusted home network and allow the LocalTV Remote executable on Private networks. Do not disable Windows Firewall. On a managed PC, ask IT to approve the program-scoped inbound rule.
  6. Restart LocalTV Remote after a network change. Choose Quit from the PC tray menu, launch the app again, and use the newly displayed link. Merely closing and reopening the pairing window does not recalculate the address.
Privacy and limitation: LocalTV Remote serves the controller over plain HTTP and WebSocket on your LAN; the transport is not encrypted. Use it only on a network you trust. It has no cloud relay, so it cannot bridge separate networks, mobile data, or router isolation.
