How do I control PowerPoint slides from my phone?

Start the slideshow on your Windows PC and keep it focused. Open LocalTV Remote on your phone, switch to the Input tab, and tap Right to advance or Left to go back. Your phone sends keys to the PC; it does not show your slides.

This is useful when your PC is connected to a projector or a room display and you want to move through slides without standing at its keyboard. LocalTV Remote runs on the PC, while the controller opens in your phone's browser. Both devices need to be reachable on the same local network. If you have not paired them, use the phone-to-PC setup guide before your presentation.

Advance and return to slides

  1. Start the slideshow on the PC. Open your presentation in PowerPoint and start Slide Show view on the Windows computer. Make sure that the slideshow, not another window or a text field, has focus.
  2. Open your paired phone controller. Scan the QR code shown by LocalTV Remote on the PC, or return to the controller address you used to pair. Enter the six-digit code displayed on the PC if prompted.
  3. Choose the Input tab. At the bottom of the phone controller, tap Input. The directional pad has Left and Right buttons. You do not need to type into the phone's keyboard field.
  4. Move through the show. Tap Right for the next animation or slide. Tap Left for the previous animation or slide. The OK button sends Enter, which can also advance the show. Tap Esc in the Keys section to end Slide Show view.

If a button changes the wrong thing

The phone sends ordinary Windows key input to whichever application currently has focus. If Right moves a cursor or selects something instead of advancing a slide, look at the PC: click the slideshow once, then try Right again. If PowerPoint is still in edit view, start Slide Show view first. PowerPoint's own presentation shortcuts distinguish advancing animations from changing slides, so one tap may reveal an animation before the slide changes.

If the phone cannot connect at all, that is a pairing or network problem rather than a slideshow shortcut problem. Follow the Wi-Fi connection checks. If the phone opens the controller but refuses the displayed code, use the rejected pairing code guide.

What this remote does not do

LocalTV Remote does not mirror the PC screen, display slide thumbnails or speaker notes on the phone, or control the PC over the internet. You still need to see the presentation on the PC or its connected display. Keep that display in view if you need to know which slide is current. The controls are Windows keys, not a PowerPoint-specific connection, so their effect depends on the focused window.
