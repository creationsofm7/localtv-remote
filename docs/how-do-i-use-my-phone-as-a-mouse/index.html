How do I use my phone as a mouse?

Install LocalTV Remote on your Windows PC, pair your phone through the QR code, and use the large trackpad in your phone’s browser. Swipe with one finger to move the Windows cursor, tap to left-click, tap with two fingers to right-click, and drag two fingers vertically to scroll.

This guide starts after installation. If you have not connected the devices yet, follow the general phone-to-PC setup guide first. The controller runs in the phone browser; the Windows app receives the gestures and turns them into system mouse input.

Use the trackpad

  1. Open the controller. Launch LocalTV Remote on the PC and scan its QR code. If the controller asks for a code, enter the six-digit code shown on the PC.
  2. Stay on the Remote tab. The large area labeled “Swipe to move cursor” is the trackpad. A one-finger swipe moves the existing Windows cursor relative to its current position.
  3. Click or right-click. Make a short one-finger tap for a left-click. Make a short two-finger tap for a right-click. Movement during the tap changes how the gesture is interpreted, so keep both fingers still for a right-click.
  4. Scroll. Put two fingers on the trackpad and move them up or down together. This sends a scroll action at the current cursor position.
  5. Adjust pointer speed. Open the controller settings and change Pointer speed if a swipe travels too far or not far enough. The setting changes how phone movement is scaled before Windows receives it.

Gesture reference

Phone gestureWindows action
One-finger swipeMove cursor
One-finger tapLeft-click
Two-finger tapRight-click
Two-finger vertical dragScroll

Limits and troubleshooting

The phone and PC must be reachable on the same local network. Guest Wi-Fi and client-isolation settings can block the connection. LocalTV Remote controls the Windows cursor; it does not create a separate pointer for each phone. If several phones are connected, their movements and clicks all affect that one shared cursor.

If a tap moves the pointer instead of clicking, lift your finger sooner and avoid moving while tapping. If nothing responds, bring the phone browser tab back to the foreground and check that the PC app is still running. Reload the controller and enter the pairing code if asked. If you changed networks, quit LocalTV Remote from the tray and launch it again before scanning the QR code.
