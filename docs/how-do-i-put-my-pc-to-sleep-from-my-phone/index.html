How do I put my PC to sleep from my phone?

With your phone connected to LocalTV Remote, leave Power button action set to Sleep, tap the power icon, and confirm the prompt. You can also select Shutdown in Remote Settings before tapping the same icon. The phone-to-PC connection ends after either action.

This works through the Windows app running on the PC and the controller in your phone browser. Pair them while the PC is awake and reachable on the local network. If you have not paired yet, follow the phone-to-PC setup steps first. The power control is for ending a session, not for starting a PC that is already asleep or turned off.

Choose Sleep or Shutdown

  1. Finish your work on the PC. Save open documents before using a power action. Shutdown closes the current Windows session; do not rely on an unsaved app to recover its changes. Sleep preserves the session differently, but saving first is still prudent.
  2. Open Remote Settings on the phone. In the connected controller, tap the settings icon in the header. Find the selector labeled Power button action.
  3. Select the action you want. Leave it on Sleep to suspend the PC. Select Shutdown if you intend to turn it off. Read the selected value before going on, since the same power icon is used for both actions.
  4. Tap the power icon. The controller asks Put the computer to sleep? or Shut down the computer now?, according to the selected action. Cancel if that is not what you meant to do.
  5. Confirm and expect disconnection. Confirm the prompt only when ready. LocalTV Remote sends the chosen command to Windows. As the PC sleeps or shuts down, its local controller stops responding and the phone connection ends.

What happens afterward

Sleep and Shutdown have different recovery paths. To resume after Sleep, wake the PC using a method supported by that PC, such as its power button or keyboard. After Shutdown, turn the PC on normally. LocalTV Remote does not provide a wake-over-network or remote power-on feature. Once Windows and the app are running again, reconnect using the current address and pairing screen if the phone does not reconnect on its own.

If the power icon seems to do nothing, first check whether the controller still says it is connected and whether the Windows machine is responding to other remote input. Then check the selected action and whether the confirmation prompt was dismissed. For a connection problem after the PC is awake again, use the phone-to-PC connection guide instead of repeatedly sending power commands.

Limits: The command is available only while the PC app is running and your phone can reach it on the same local network. The phone does not remain connected after Sleep or Shutdown, and this control cannot wake or start the PC again. Windows or another application may prevent an action from completing, so check the PC if the expected state does not occur.
