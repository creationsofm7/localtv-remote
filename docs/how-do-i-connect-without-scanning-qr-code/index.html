How do I connect without scanning the QR code?

Open the current controller address shown by LocalTV Remote in your phone browser, then enter the six-digit PIN displayed on the PC.

Connect by address and PIN

  1. Open LocalTV Remote on the PC. If it is already in the system tray, open its pairing window from there. The window shows both a local address and a six-digit pairing code.
  2. Check that both devices share a local network. The phone can be on Wi-Fi while the PC uses Wi-Fi or Ethernet, provided both reach the same LAN. Mobile data, guest isolation, and separate networks will not work because there is no cloud relay.
  3. Type the complete address into the phone browser. Include http://, the numeric IP address, and the port. A typical address resembles http://192.168.1.25:6776, but copy what the PC shows rather than using this example.
  4. Enter the six-digit PIN. The QR code simply packages the same current address with that PIN. Manual entry reaches the same controller and authentication flow.
  5. Wait for Connected before sending input. After successful pairing, the controller stores a session token in that browser’s local storage. Returning in the same browser profile may resume the session while the PC app remains running.

Why an old address may stop working

The six-digit PIN is deterministically derived from the PC’s hostname and Windows username; it is not a short-lived code that expires every few minutes. The address is the part most likely to change. A router can assign the PC another local IP address, and the daemon can choose a fallback port when its preferred port is already occupied.

Reopen the pairing window to get the current address. If you renamed the PC or changed Windows accounts, use the PIN shown now rather than a previously saved code.

Privacy and limitation: the controller is served over plain HTTP on the LAN, so its traffic is not encrypted. Avoid untrusted or public networks. The local pairing page that reveals the PIN is restricted to the PC itself; read the PIN from the desktop window.
