How do I control an Ethernet PC from my phone?

Connect the Windows PC to your router by Ethernet and the phone to that router’s Wi-Fi, then use LocalTV Remote normally. The devices do not need to use the same connection type; they need IP connectivity to each other on the same reachable local network.

LocalTV Remote listens on the PC’s network interfaces and builds the controller link from a non-internal IPv4 address. In a typical home network, wired Ethernet and the main Wi-Fi belong to the same LAN, so the QR code opens the wired PC’s controller from the phone.

Connect the wired PC

  1. Connect Ethernet and verify Windows networking. Plug the PC into the router or network switch. Confirm that Windows has a working local network connection before opening LocalTV Remote.
  2. Join the phone to the matching Wi-Fi. Use the main Wi-Fi network served by the same router or routed LAN. Avoid mobile data and guest Wi-Fi while pairing.
  3. Launch LocalTV Remote on the PC. Its host window displays a QR code and pairing code. The QR link contains the LAN address selected by the app.
  4. Scan from the phone. Open the link from the phone camera and enter the six-digit code if requested. When authenticated, the trackpad and other controls appear.
  5. Use the remote. Mouse, keyboard, and volume commands travel between the phone browser and the PC over the reachable local network.

For the complete installation and controller walkthrough, see how to control a PC from a phone. Ethernet changes the network path, not the controller workflow.

If the QR link does not open

First turn off mobile data temporarily so the phone uses Wi-Fi. Check that the phone is not on a guest SSID and that the wired and wireless networks can communicate. Windows Firewall must allow the LocalTV Remote service on the current network profile. Corporate access points, VLANs, VPNs, and “AP isolation” settings may block device-to-device traffic even when both devices have internet access.

Ethernet support is not a promise that every wired and wireless network is bridged. LocalTV Remote works only when the phone can reach the PC’s displayed LAN address and port. It does not provide an internet relay or bypass router, firewall, or organizational network policy.
