How do I control PC volume from my phone?

Connect your phone to LocalTV Remote and use the volume controls on the Remote tab. The minus and plus buttons lower or raise the Windows system volume, the center display shows the current percentage, and the speaker button toggles mute.

You only install LocalTV Remote on the Windows PC. Your phone opens its controller in a browser over the local network. If you have not paired the devices, use the general setup guide before continuing.

Change the Windows volume

  1. Open the connected controller. Scan the QR code shown by LocalTV Remote or return to the controller URL on a previously used phone. Enter the displayed pairing code when the page requests it.
  2. Use the Remote tab. The volume row sits below the trackpad and navigation buttons. Wait for its center value to change from “--” to a percentage; that indicates that the controller has received volume state from Windows.
  3. Tap minus or plus. Each tap adjusts the requested volume by three percentage points. Start with a few taps and check the sound before raising it further.
  4. Toggle mute. Tap the speaker button near the top of the controller to mute or unmute Windows audio. This is a toggle, so the result depends on the current mute state reported by the PC.
  5. Check the displayed result. The number updates as you tap and then reflects the level reported by Windows. Another phone or a keyboard volume key can change the same system volume.

Which volume does it control?

LocalTV Remote controls the Windows system output level through its volume controller. It is not a per-application mixer: it does not provide separate sliders for a browser, game, call, or music player. The audible result can also depend on the selected Windows output device, an application’s own volume setting, and any hardware volume control on speakers or a display.

ControlBehavior
MinusTargets 3 percentage points lower
PlusTargets 3 percentage points higher
Mute buttonToggles Windows system mute
PercentageShows the latest known system level

Limits and troubleshooting

The phone and PC must remain reachable on the same local network, and the Windows app must be running. Multiple connected phones operate the same system volume, so one person’s adjustment is visible to the others. LocalTV Remote cannot raise sound that is muted inside an individual app or turned down on external hardware.

If the percentage remains “--”, verify that the controller is connected and reload it once. If the number changes but the sound does not, check the active Windows output device, the app’s mixer level, and the physical speaker or monitor volume.
