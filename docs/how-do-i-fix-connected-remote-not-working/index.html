How do I fix a connected remote that is not working?

First test different control types, then put focus on a normal desktop app. “Connected” confirms the phone authenticated to the PC server; it does not prove every Windows input action can reach the current target.

Use the result to narrow the cause

TestIf it worksIf it fails
Volume up or downThe connection and volume path work.Check that LocalTV Remote is still running and Windows audio is available.
Move the pointer on the desktopThe Win32 input backend is available.Restart LocalTV Remote; its native input backend may not have initialized.
Type into NotepadKeyboard injection works in a normal app.Click inside the document first, then retry one key.
Control only one elevated appNormal desktop input works.The target may be protected by a Windows privilege boundary.

Check controls, focus, and Windows restrictions

  1. Confirm the phone still says Connected. If it says Reconnecting or Disconnected, solve the network path first. Input messages are ignored while the WebSocket is closed or unauthenticated.
  2. Test volume separately from pointer and keyboard. The daemon routes volume through the Windows audio controller, while mouse and keyboard events require the Win32 input backend. One working path does not prove the other is healthy.
  3. Give the target app focus. Click the text field or window you want to control using the PC once, then send a simple key from the phone. Keyboard input goes to the foreground Windows target; LocalTV Remote does not choose a background text field for you.
  4. Try an ordinary desktop target. Use Notepad or the Windows desktop. Secure screens, permission prompts, and apps running with higher privileges can reject input sent by a non-elevated process because Windows separates processes by integrity level.
  5. Restart the app if all pointer and keyboard controls fail. The daemon logs when its Windows input backend cannot initialize. Closing and reopening LocalTV Remote gives the native injector another initialization attempt.
  6. Update to the latest release. Install over the existing version, reopen it, and pair again if the in-memory trusted session was cleared.
Do not disable User Account Control. UAC and secure-desktop restrictions are Windows security boundaries. LocalTV Remote’s daemon treats elevation requests as a no-op and does not provide a bypass. Operate the elevated target locally, or use a workflow approved by your administrator.

LocalTV Remote’s daemon has no embedded browser. Navigation commands intended for an embedded page are intentionally ignored, while supported media shortcuts are translated to Windows key presses. Diagnose the specific control that fails instead of treating every button as the same path.
