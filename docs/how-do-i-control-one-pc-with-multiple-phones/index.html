How do I control one PC with multiple phones?

Open the same LocalTV Remote pairing link on each phone and authenticate each browser. All connected phones can send mouse, keyboard, and volume commands to the same Windows PC, but they do not receive separate desktops or separate cursors.

Install and run one copy of LocalTV Remote on the PC. Every phone must be able to reach that PC on the local network. For first-time setup details, start with the general phone-to-PC guide.

Connect each phone

  1. Launch LocalTV Remote on the PC. Show its pairing window while people scan the QR code or enter the controller address. You can close the pairing window afterward; leave LocalTV Remote running in the system tray.
  2. Connect the first phone. Scan the QR code, open the browser controller, and enter the six-digit pairing code if prompted. Wait until the remote controls appear.
  3. Repeat on another phone. Scan the same currently displayed QR code with each additional phone. Everyone gets their own remote in their own browser, with no need to pass one phone around.
  4. Confirm the connected count. The PC host page tracks authenticated clients. Closing a controller tab or losing its network connection removes that client after the connection ends.
  5. Coordinate before sending input. Decide who is controlling at a given moment. Commands are processed as they arrive, so simultaneous swipes, clicks, typing, or volume changes can conflict.

What is shared?

ItemBehavior with multiple phones
Mouse pointerOne shared Windows cursor
Keyboard focusOne active Windows field or application
VolumeOne shared Windows system level and mute state
Browser connectionA separate authenticated connection per phone
Desktop sessionNo separate session or private view per phone

Pairing and reconnection limits

Your browser remembers pairing information, but restarting the PC app clears its list of active sessions. If a phone asks to pair again, scan the QR code or enter the code shown on the PC. Clearing browser data or switching to another browser can also require pairing again.

Everyone controls the same PC input state. LocalTV Remote does not assign ownership, queue turns, label each person’s commands, or isolate one phone from another. Only share the pairing code with people you want to let control the computer.

If one phone cannot join

Check that it is on a network that can reach the PC and that its browser opened the same PC address as the working phones. Guest Wi-Fi can isolate clients even when the network name looks similar. If an old page rejects authentication, reopen the current QR link and use the current code.
